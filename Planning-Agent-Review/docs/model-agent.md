# 模型适配与 Agent 原理

## 检索优先于记忆

书目和摘要持续变化，放在可更新语料库中比写入模型参数更易校正和引用。基础模型负责语言理解与组织；RAG 提供本轮可核查的来源事实；微调只塑造重复出现的输出习惯和任务流程。

## 微调生命周期

1. 先定义可观察的目标行为和失败类型。
2. 建立来源可追溯、许可明确、去重后的训练样本。
3. 按文献或来源分组隔离训练、验证和测试集，防止同源内容跨集合泄漏。
4. 选择参数高效适配方法，记录基础模型版本、训练配置、数据摘要和随机状态。
5. 用未参与训练的样本比较基线与适配模型，并检查引用准确性、事实边界和拒答行为。
6. 将适配器与基础模型分开发布；部署格式转换后重新验证。

## Agent 工作循环

Agent 读取用户意图，规划所需证据来源，调用检索或外部工具，检查返回结果，再整理回答。工具应有窄接口、明确输入输出、超时和错误处理。执行轨迹只记录必要诊断信息，不记录密钥。涉及证据不足时，Agent 应标明限制而不是补造细节。

## 评估原则

评估应覆盖检索召回、来源正确性、引用可定位性、合成质量和拒绝无证据断言等不同维度。使用相同问题与相同证据预算比较方案；数据集和检索策略的局限应随结果一起说明。自动指标只提供诊断信号，不能代替人工核对。
