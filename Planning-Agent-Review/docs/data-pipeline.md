# 采集、语料与索引生命周期

## 采集原则

采集任务由明确的范围配置驱动。请求按页执行，遵循来源服务的速率与额度限制，并记录检查点。重试应可区分暂时性网络错误与永久性请求错误。原始响应应保留在受控数据目录，避免与公开源码混合。

## 规范化和质量控制

规范化统一标题、摘要、作者、来源、年份、类型和标识符等字段。去重优先使用稳定标识符，再结合规范化标题与年份处理缺少标识符的记录。每一步应输出可审计计数和异常样本，而不是静默丢弃记录。

## 语料版本

一次完成的采集和清洗形成不可变语料快照，附带来源说明、字段版本、记录计数和校验摘要。下游索引记录它使用的语料版本。新数据到来时建立新快照并重建或增量更新索引，保留回滚路径。

## 检索索引

- **全文索引**适合精确术语、缩写和短语匹配。
- **向量索引**用于语义近邻召回，其效果受文本切分和嵌入模型影响。
- **关系索引**表达文献、主题或引用实体间的结构关系，支持跨记录扩展。

多路召回后统一去重和排序，并将摘要、元数据、来源标识及检索路径一起交给证据融合层。索引文件是派生数据，不应作为唯一语料备份。

## 运行与维护

采集、规范化、索引构建和检索分别执行并报告状态。长任务应支持检查点、幂等重跑、空间预检和构建后校验。记录数据库和向量文件的版本、大小与哈希，便于发现不完整拷贝。
