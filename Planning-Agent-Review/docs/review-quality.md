# 文献综述质量控制原则

本系统把综述质量视为证据处理和论证组织问题，而不只看措辞。

1. **覆盖范围与证据量**：用互补检索分面扩展候选证据，记录候选数、筛选规则和上下文限额。少量排序结果只能支持范围有限的草稿，不能冒充穷尽检索。
2. **结论边界**：将“本次检索未发现”与“领域不存在”分开。数据库、年份、排序、摘要可得性等限制要进入证据范围说明。
3. **跨研究综合**：按证据所代表的研究路径或主题组织论证，比较研究对象、地点、尺度、设计和发现。逐篇摘要只用于提供证据锚点，不代替综合。
4. **数量与效应值**：每个数字都要关联来源、结果变量、场景和研究设计。不同人群、温度指标或方法下的结果不能合并成单一效果区间；避免在多个章节重复同一数值。
5. **测量可比性**：区分不同操作化指标。传感器、数据集或分析方法不能单独证明研究测量了某个特定构念；资料未报告时保留未知。
6. **缺口可追溯性**：把证据矩阵作为推导缺口的中间环节。矩阵逐项记录研究设计、范围、指标、介入和证据类型；缺少信息写为未报告，不能将摘要空白推成全文没有。

相关但不直接检验目标干预或结果的文献可用于背景或方法比较，不能用作效果证据。引用应回到可核查的原始来源；模型判读本身不是独立的专家筛选。
